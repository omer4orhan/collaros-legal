collarOS privacy policy

Last updated: 21 September 2026

Who we are

collarOS is a private operations workspace for window-cleaning businesses. This page describes how it handles information it receives from Google Calendar. Contact: omer4orhan@gmail.com.

What collarOS reads from Google Calendar

When a business connects a Google Calendar, collarOS reads events in that one calendar. It considers only events the business has marked for collarOS. From those events it keeps the start time, end time, time zone and an encrypted identifier of the event, so that the event can be linked to a scheduled visit. It does not show or keep other event details such as descriptions or attendees.

What collarOS writes to Google Calendar

collarOS can create or update calendar entries that show which team member is assigned to a visit. These entries contain a short label and the visit time. They do not contain customer names or addresses.

How the information is used

The information is used only to provide these scheduling features to the business that connected the calendar. It is not sold, not used for advertising, not shared with third parties other than the hosting provider that runs the service, and not used to train artificial intelligence models.

Google API Services User Data Policy

collarOS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage, access and deletion

Information is stored in a protected database. Access tokens are kept in protected server configuration, not in the browser. A business can disconnect collarOS at any time at myaccount.google.com/permissions. To ask for information to be deleted, write to the contact address above.

Changes

If this policy changes, the date above changes with it.
